Debrief

What the three rounds add up to

A note today isn't worth the same as a note later (Round 1). Interest earns interest (Round 2). To compare cash flows at different points in time, everything has to be converted to a common point in time — usually today (Round 3). That conversion is present and future value.

PV = FV / (1 + r)n   ·   FV = PV × (1 + r)n
